# Native provider recording run

Tier 2 under the owner's native long-visit, recovery and merge direction. Connect
NativeSourceStartOwner's Core authorization/stop proof to the native encrypted PCM
recorder and its continuation owner. A provider run retains physical and remote
stop custody across awaits. Original preparation/proof is immutable through lease
renewal. Native source validation checks the original issued run and current
account/revision, while the PCM continuation enforces the renewed deadline.

The shared gate distinguishes legacy microphone and native encrypted consumers.
A renderer calling the legacy plugin cannot consume an encrypted owner's permit.
All legacy probes and the retained encrypted recorder must be idle before starting,
recovering or confirming cessation. Plugin reload never replaces an older probe.
A failed start is one-use; retirement fences pending permission/authorization and
readiness. Stop closes the graph, verifies shared idle, then acknowledges the exact
original Core proof. Failed closure or stop acknowledgement retains retry custody.

Use the existing Apple permission/audio adapters, source owner, PCM engine, queue,
encryption and renewal. No new external dependency, renderer audio or credential
surface. The native provider run is a host component; durable flow journal,
Capacitor commands and provider UI routing remain next in the dependent stack.
Existing installed foreground recording is not switched or given background
capability by this change. Preserve desktop-specific stop-only cancellation.

Validate real gate/source/run code with synthetic authority and controlled audio
ports. Cover both consumer routes, overlapping owners, repeated calls, late
permission/prepare/authorize/readiness, post-claim failure, physical and Core stop
retry, original proof preservation, account/session change and terminal capture.
Compile iOS17 and regress retained provider/transport/source build paths. Local
checks and exact-head implementer review precede the authorized merge. No device,
ambient microphone, meeting, fixture mutation, deployment or installation.

Recovery: leave the new run unselected. Do not downgrade over active native custody,
remove queue/key/source journals, or acknowledge Core stop before physical idle.
