The full supported parent requirement passes a separate read-only ordinary macOS static check against signed Store101. This is evidence for the grammar defect; it does not qualify a later XPC, authentication, or recording path.

Replace all five Store requirement strings (six Boolean clauses) with supported `exists` syntax and require the signed value to have Core Foundation Boolean type and value true. Parent admission and revalidation retain the existing Apple anchor, Team, identifier, group, and kernel process checks.
